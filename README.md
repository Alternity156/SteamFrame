Requires MelonLoader 0.5.7.

To install MelonLoader on the Steam Frame you need to download the manual install of MelonLoaderx64, unzip it to the root folder of Audica. Then you need to add WINEDLLOVERRIDES="version=n,b" %command% to Audica's launch options in Steam. Finally, the most annoying part, you'll need to copy your MelonLoader folder from your PC, one that has already ran successfully, and transfer it to your Frame.
